## 1. 学术叙事

### 1.1 核心故事

超透镜图像退化可以视为**加性噪声+模糊**的复合退化。扩散模型的**反向去噪过程**天然适合渐进式修复。我们设计**轻量级扩散专家**，在MoE框架内实现渐进式去噪。

### 1.2 创新点

- 引入**轻量级扩散模块**，在专家内部实现渐进式去噪
- 设计**退化感知扩散调度**，根据SVFE调整去噪步数
- 实现**"频率-扩散"双维度渐进修复**

### 1.3 顶会叙事

By leveraging spatially-variant frequency embedding to adaptively schedule denoising steps, our model addresses the compound degradation (noise + blur) in metalens endoscopy images through a physics-inspired progressive restoration process."

## 2. 技术实现

### 2.1 核心模块代码

#### LightweightDiffusionExpert类

**插入位置**：在`SpatiallyVariantFreqEmbedding`类之后（约第768行之后）

```python
##########################################################################
## Lightweight Diffusion Expert
class LightweightDiffusionExpert(nn.Module):
    """
    轻量级扩散专家：渐进式去噪修复
    """
    def __init__(self, dim, num_steps=4):
        super().__init__()
        self.num_steps = num_steps
        
        # 去噪网络（U-Net风格）
        self.denoiser = nn.Sequential(
            nn.Conv2d(dim, dim * 2, 3, padding=1),
            nn.GELU(),
            nn.Conv2d(dim * 2, dim * 2, 3, padding=1),
            nn.GELU(),
            nn.Conv2d(dim * 2, dim, 3, padding=1)
        )
        
        # 时间步嵌入
        self.time_embed = nn.Sequential(
            nn.Linear(1, dim),
            nn.GELU(),
            nn.Linear(dim, dim)
        )
        
    def forward(self, x, degradation_level=None):
        """
        x: [B, C, H, W] - 退化特征
        degradation_level: [B, 1] - 退化强度（0-1），如果None则使用固定步数
        """
        if degradation_level is None:
            # 固定步数渐进去噪
            x_denoised = x
            for t in range(self.num_steps):
                # 时间步嵌入
                t_embed = torch.ones(x.shape[0], 1, device=x.device) * (t / self.num_steps)
                t_feat = self.time_embed(t_embed)  # [B, C]
                t_feat = t_feat.unsqueeze(-1).unsqueeze(-1).expand(-1, -1, x.shape[2], x.shape[3])
                
                # 去噪
                noise_pred = self.denoiser(x_denoised + t_feat)
                x_denoised = x_denoised - 0.1 * noise_pred  # 渐进去噪
        
        else:
            # 根据退化强度自适应调整步数
            num_steps_adaptive = (degradation_level * self.num_steps).int().clamp(1, self.num_steps)
            x_denoised = x
            for b in range(x.shape[0]):
                steps = num_steps_adaptive[b].item()
                x_b = x[b:b+1]
                for t in range(steps):
                    t_embed = torch.ones(1, 1, device=x.device) * (t / steps)
                    t_feat = self.time_embed(t_embed)
                    t_feat = t_feat.unsqueeze(-1).unsqueeze(-1).expand(-1, -1, x_b.shape[2], x_b.shape[3])
                    noise_pred = self.denoiser(x_b + t_feat)
                    x_b = x_b - 0.1 * noise_pred
                if b == 0:
                    x_denoised = x_b
                else:
                    x_denoised = torch.cat([x_denoised, x_b], dim=0)
        
        return x_denoised
```
