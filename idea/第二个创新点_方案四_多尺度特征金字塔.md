## 1. 学术叙事

### 1.1 核心故事

超透镜的退化是**多尺度的**——中心区域细节损失（细粒度），边缘区域结构扭曲（粗粒度）。单一尺度处理无法同时应对。我们引入**特征金字塔网络（FPN）**，在不同尺度上渐进式修复。

### 1.2 创新点

- 设计**多尺度特征金字塔**，同时处理细粒度和粗粒度退化
- 实现**渐进式修复策略**，从粗到细逐步恢复
- 结合SVFE，实现**"频率-尺度"多维度退化感知**

### 1.3 顶会叙事

> "We propose a multi-scale feature pyramid expert that progressively restores metalens endoscopy images from coarse to fine. By integrating spatially-variant frequency embedding, our model simultaneously addresses fine-grained detail loss in central regions and coarse-grained structural distortion in edge areas, ensuring comprehensive restoration across all scales."

## 2. 技术实现

### 2.1 核心模块代码

#### MultiScalePyramidExpert类

**插入位置**：在`SpatiallyVariantFreqEmbedding`类之后（约第768行之后）

```python
##########################################################################
## Multi-Scale Feature Pyramid Expert
class MultiScalePyramidExpert(nn.Module):
    """
    多尺度特征金字塔专家：渐进式修复
    """
    def __init__(self, dim, num_scales=3):
        super().__init__()
        self.num_scales = num_scales
        
        # 多尺度特征提取
        self.scale_encoders = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(dim, dim, 3, padding=1),
                nn.GELU(),
                nn.Conv2d(dim, dim, 3, padding=1)
            ) for _ in range(num_scales)
        ])
        
        # 尺度融合
        self.scale_fusion = nn.Sequential(
            nn.Conv2d(dim * num_scales, dim, 1),
            nn.GELU(),
            nn.Conv2d(dim, dim, 3, padding=1)
        )
        
    def forward(self, x):
        # x: [B, C, H, W]
        B, C, H, W = x.shape
        
        # 多尺度特征提取
        scale_feats = []
        for i, encoder in enumerate(self.scale_encoders):
            # 下采样到不同尺度
            scale_factor = 2 ** i
            if scale_factor > 1:
                x_scaled = F.interpolate(x, size=(H // scale_factor, W // scale_factor), mode='bilinear', align_corners=False)
            else:
                x_scaled = x
            
            # 编码
            feat = encoder(x_scaled)
            
            # 上采样回原尺寸
            if scale_factor > 1:
                feat = F.interpolate(feat, size=(H, W), mode='bilinear', align_corners=False)
            
            scale_feats.append(feat)
        
        # 融合多尺度特征
        fused = torch.cat(scale_feats, dim=1)  # [B, C*num_scales, H, W]
        out = self.scale_fusion(fused)
        
        return out + x  # 残差连接
```
