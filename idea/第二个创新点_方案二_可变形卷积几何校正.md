## 1. 学术叙事

### 1.1 核心故事

超透镜的**场曲（Field Curvature）**和**畸变（Distortion）**导致图像边缘出现几何变形，病灶可能被拉伸或压缩。传统固定卷积无法适应这种**空间变异的几何退化**。

### 1.2 创新点

- 引入**可变形卷积（Deformable Convolution）**，让卷积核能够根据局部几何畸变自适应调整采样位置
- 设计**几何校正专家**，专门修复边缘区域的几何变形
- 结合SVFE，实现**"频率-几何"双维度退化感知**

### 1.3 顶会叙事

> "We introduce deformable convolution-based experts that adaptively adjust sampling locations to compensate for field curvature and distortion in metalens endoscopy. By integrating spatially-variant frequency embedding, our model simultaneously addresses optical aberrations and geometric deformations, ensuring accurate preservation of lesion morphology for clinical diagnosis."

### 2.1 核心模块代码

#### DeformableConvExpert类

**插入位置**：在`SpatiallyVariantFreqEmbedding`类之后（约第768行之后）

```python
##########################################################################
## Deformable Convolution Expert
class DeformableConvExpert(nn.Module):
    """
    可变形卷积专家：自适应调整采样位置，校正几何畸变
    """
    def __init__(self, dim, kernel_size=3, padding=1):
        super().__init__()
        # 标准卷积：提取特征
        self.conv = nn.Conv2d(dim, dim, kernel_size, padding=padding, bias=False)
        
        # 偏移量预测网络：预测每个采样点的偏移
        self.offset_conv = nn.Sequential(
            nn.Conv2d(dim, dim, 3, padding=1),
            nn.GELU(),
            nn.Conv2d(dim, 2 * kernel_size * kernel_size, 1)  # 每个位置2个偏移(x,y)
        )
        
        # 调制掩码：控制每个采样点的权重
        self.mask_conv = nn.Sequential(
            nn.Conv2d(dim, dim, 3, padding=1),
            nn.GELU(),
            nn.Conv2d(dim, kernel_size * kernel_size, 1),
            nn.Sigmoid()
        )
        
        self.kernel_size = kernel_size
        self.padding = padding
        
    def forward(self, x):
        # x: [B, C, H, W]
        B, C, H, W = x.shape
        
        # 预测偏移量：[B, 2*K*K, H, W]
        offset = self.offset_conv(x)
        # 预测调制掩码：[B, K*K, H, W]
        mask = self.mask_conv(x)
        
        # 使用可变形卷积（需要torchvision >= 0.9.0）
        # 如果没有deform_conv2d，使用简化版本
        try:
            from torchvision.ops import deform_conv2d
            weight = self.conv.weight
            out = deform_conv2d(
                x, offset, weight, 
                padding=self.padding,
                mask=mask
            )
        except ImportError:
            # 简化版本：使用双线性插值实现可变形采样
            out = self._deform_conv_simple(x, offset, mask)
        
        return out
    
    def _deform_conv_simple(self, x, offset, mask):
        """
        简化版可变形卷积：使用双线性插值
        """
        B, C, H, W = x.shape
        K = self.kernel_size
        
        # 生成标准网格
        y_coords, x_coords = torch.meshgrid(
            torch.arange(H, device=x.device, dtype=x.dtype),
            torch.arange(W, device=x.device, dtype=x.dtype),
            indexing='ij'
        )
        grid = torch.stack([x_coords, y_coords], dim=0).unsqueeze(0)  # [1, 2, H, W]
        grid = grid.expand(B, -1, -1, -1)  # [B, 2, H, W]
        
        # 重塑offset和mask
        offset = offset.view(B, 2, K, K, H, W)  # [B, 2, K, K, H, W]
        mask = mask.view(B, K, K, H, W)  # [B, K, K, H, W]
        
        # 对每个采样点进行可变形采样
        output = torch.zeros_like(x)
        for i in range(K):
            for j in range(K):
                # 计算偏移后的坐标
                offset_ij = offset[:, :, i, j, :, :]  # [B, 2, H, W]
                grid_ij = grid + offset_ij
                
                # 归一化到[-1, 1]
                grid_ij[:, 0, :, :] = 2.0 * grid_ij[:, 0, :, :] / (W - 1) - 1.0
                grid_ij[:, 1, :, :] = 2.0 * grid_ij[:, 1, :, :] / (H - 1) - 1.0
                grid_ij = grid_ij.permute(0, 2, 3, 1)  # [B, H, W, 2]
                
                # 双线性插值采样
                sampled = F.grid_sample(x, grid_ij, mode='bilinear', padding_mode='zeros', align_corners=True)
                # 应用调制掩码
                mask_ij = mask[:, i, j, :, :].unsqueeze(1)  # [B, 1, H, W]
                output = output + sampled * mask_ij
        
        return output
```
